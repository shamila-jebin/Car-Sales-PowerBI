# Car-Sales-PowerBI
Interactive Car Sales Analytics Dashboard built with Power BI to analyze sales, vehicle performance, regional trends, profitability, and salesperson performance.
 🚗 Car Sales Analytics Dashboard – Power BI

 📊 Project Overview

This project presents an interactive **Car Sales Analytics Dashboard** built using Microsoft Power BI.

The dashboard transforms raw car sales data into meaningful business insights through interactive KPIs, charts, filters, and multiple analytical pages.

The project focuses on understanding sales performance, vehicle trends, regional performance, profitability, and salesperson performance.

 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall car sales performance
- Track sales and profit trends
- Compare sales across car companies and models
- Analyze vehicle characteristics such as fuel type and body type
- Understand city-wise sales performance
- Analyze revenue, cost, and profitability
- Evaluate salesperson performance
- Create an interactive and user-friendly Power BI dashboard
